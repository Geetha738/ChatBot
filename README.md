This is a console-based Java chatbot application with a simple frontend interface built using HTML, CSS, and JavaScript. The chatbot interacts with users through predefined responses and simulates a conversation flow. The project demonstrates core Java programming concepts along with basic frontend-backend integration.

Features

User-friendly chat interface
Continuous conversation with input validation
Predefined responses based on user input
Simple UI design using HTML and CSS

Technologies Used

Java (for chatbot logic)
HTML, CSS, JavaScript (for frontend interface)
Scanner class for input handling in Java
